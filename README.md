# Personal Website

This project is a personal website designed to showcase my portfolio and serve as a platform for experimenting with new technologies and projects. It is built using React, Next.js, and TypeScript, and was previously hosted on AWS. The website also utilizes Tailwind CSS and daisyUI for styling. It is not currently being hosted.

## Technologies Used
- React
- Next.js
- TypeScript
- Tailwind CSS
- daisyUI
- AWS
